# Prospectalo -- CLAUDE.md

## Project Overview

**Prospectalo** ("Motor de ventas") is a local business growth SaaS for Spanish-speaking markets. It helps barbershops, salons, restaurants, and similar businesses grow through automated review requests, referral programs, reactivation campaigns, and slow-slot promotions -- without paid advertising.

Stack: React + TypeScript (Vite) / tRPC / Drizzle ORM / MySQL / Tailwind CSS + shadcn/ui.
